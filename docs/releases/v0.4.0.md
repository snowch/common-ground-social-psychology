A visual refinement of Common Ground using the Frontend Design skill.

- A navy cover and expanded café illustration, with the same fictional cast.
- Refined typography, chapter rows, explicit progress badges, and mobile spacing.
- Narration/navigation controls before the slide, plus quieter evidence disclosures.
- Matching download and study-companion pages.
- Updated slide PDFs, chapter PDFs, and narrated offline decks.

Kokoro **af_heart**, speed 1.0, recordings, pauses, questions, answers, and progress storage are preserved. The existing OFL fonts and complete asset notices remain included; no third-party artwork or font was added.

Validation covers all 80 slides, 60 feedback variants, 150 decoded recordings, keyboard focus, storage fallbacks, responsive layout, native disclosures, automated accessibility checks, print bounds, and offline package integrity. See `docs/design-v0.4.0.md` and the QA records for scope and limits.

Open the public course at https://snowch.github.io/common-ground-social-psychology/ or extract the release ZIP and open `common-ground/index.html`. New downloads are required to update previously saved offline copies.
